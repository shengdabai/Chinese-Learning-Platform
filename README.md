# 中文学堂 — 全球中文学习者的在线课程平台

> **系统化学习中文，从零基础到精通** — 专业的中文学习课程平台，提供 HSK 考试、商务中文、日常对话等精选课程。

## 当前可用范围

当前仓库是前端演示，内置 6 条模拟课程数据，其中 5 门可浏览、1 门标记为即将上线。可在本地浏览课程、按关键词/分类/级别筛选、排序、查看详情，以及添加和移除购物车条目。每门数字课程在购物车中只保留一份，重复加入不会增加数量或合计；未上线课程不能加入。搜索与筛选条件保存在网址中，可刷新或分享；购物车只保存在内存中，刷新后会清空。

仓库尚未接入账号、支付、视频试听、教学练习、学习进度或会员服务。登录会明确失败，结算会提示无法下单，不会产生扣款。个人中心、我的课程、订单和联系页面仍为占位；注册、帮助和法律页面尚未提供。

下文的课程规模、学员统计、教学能力、优惠和定价属于产品规划或演示内容，不代表真实经营数据或已交付服务。

## 产品简介

中文学堂是一个面向全球中文学习者的在线课程平台，提供从零基础入门到 HSK 高级、商务中文、文化理解的完整学习路径。无论你是为了考试、工作还是兴趣，都能在这里找到适合的课程。

**适合谁用：**
- HSK 考生：系统备考，从 HSK1 到 HSK6 全覆盖
- 商务人士：商务中文实战课程，掌握职场沟通
- 零基础学习者：从拼音、汉字开始，循序渐进
- 文化爱好者：了解中国文化、历史、饮食

## 开发

```bash
npm run dev      # 开发模式
npm run check    # TypeScript 类型检查
npm run lint     # 代码检查
npm test         # Vitest 测试（包含 jsdom 交互测试）
npm run build    # 生产构建，不部署
npm run preview  # 预览本地构建
```

依赖版本以 `package-lock.json` 为准。CI 仅运行检查、测试、构建和容器构建，不包含部署任务。原先引用不存在脚本的 `deploy` 命令已移除。

## 本地构建服务与容器

执行 `npm run build` 后，运行 `npm start` 可用 Node 内置服务访问 `http://localhost:3000`，通过 `PORT` 更改端口。服务不读取账号配置，不接入认证或支付。

容器构建使用锁文件安装依赖；运行阶段不安装全局包，以 `node` 用户启动同一个静态服务。`.dockerignore` 只允许构建所需输入进入上下文，排除本地依赖、环境文件和工具状态。可在装有 Docker 的环境运行 `docker build -t chinese-learning-platform .`，再运行 `docker run --rm -p 3000:3000 chinese-learning-platform`。

HTML 导航支持课程详情等深链刷新；缺失的静态资源和 `/api` 请求返回 404。`GET /healthz` 在构建入口可读时返回 200，入口缺失时返回 503。服务只接受 GET / HEAD，不开放跨域读取，也不实现 API、视频流或购买流程。
